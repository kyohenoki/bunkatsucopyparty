- [the browser](/docs/the-browser/the-browser) - accessing a copyparty server using a web-browser
  - [tabs](/docs/the-browser/tabs) - the main tabs in the ui
  - [hotkeys](/docs/the-browser/hotkeys) - the browser has the following hotkeys
  - [navpane](/docs/the-browser/navpane) - switching between breadcrumbs or navpane
  - [thumbnails](/docs/the-browser/thumbnails) - press `g` or `田` to toggle grid-view instead of the file listing
  - [zip downloads](/docs/the-browser/zip-downloads) - download folders (or file selections) as `zip` or `tar` files
  - [uploading](/docs/the-browser/uploading) - drag files/folders into the web-browser to upload
    - [file-search](/docs/the-browser/uploading/file-search) - dropping files into the browser also lets you see if they exist on the server
    - [unpost](/docs/the-browser/uploading/unpost) - undo/delete accidental uploads
    - [self-destruct](/docs/the-browser/uploading/self-destruct) - uploads can be given a lifetime
    - [race the beam](/docs/the-browser/uploading/race-the-beam) - download files while they're still uploading ([demo video](http://a.ocv.me/pub/g/nerd-stuff/cpp/2024-0418-race-the-beam.webm))
    - [incoming files](/docs/the-browser/uploading/incoming-files) - the control-panel shows the ETA for all incoming files
  - [file manager](/docs/the-browser/file-manager) - cut/paste, rename, and delete files/folders (if you have permission)
  - [shares](/docs/the-browser/shares) - share a file or folder by creating a temporary link
  - [batch rename](/docs/the-browser/batch-rename) - select some files and press `F2` to bring up the rename UI
  - [rss feeds](/docs/the-browser/rss-feeds) - monitor a folder with your RSS reader
  - [opds feeds](/docs/the-browser/opds-feeds) - browse and download files from your e-book reader
  - [recent uploads](/docs/the-browser/recent-uploads) - list all recent uploads
  - [media player](/docs/the-browser/media-player) - plays almost every audio format there is
    - [playlists](/docs/the-browser/media-player/playlists) - create and play [m3u8](https://en.wikipedia.org/wiki/M3U) playlists
    - [creating a playlist](/docs/the-browser/media-player/creating-a-playlist) - with a standalone mediaplayer or copyparty
    - [audio equalizer](/docs/the-browser/media-player/audio-equalizer) - and [dynamic range compressor](https://en.wikipedia.org/wiki/Dynamic_range_compression)
    - [fix unreliable playback on android](/docs/the-browser/media-player/fix-unreliable-playback-on-android) - due to phone / app settings
  - [textfile viewer](/docs/the-browser/textfile-viewer) - with realtime streaming of logfiles and such ([demo](https://a.ocv.me/pub/demo/logtail/))
  - [markdown viewer](/docs/the-browser/markdown-viewer) - and there are _two_ editors
    - [markdown vars](/docs/the-browser/markdown-viewer/markdown-vars) - dynamic docs with serverside variable expansion
  - [other tricks](/docs/the-browser/other-tricks)
  - [searching](/docs/the-browser/searching) - search by size, date, path/name, mp3-tags, ...
